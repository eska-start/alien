# 외계인 친구들

어린이용 터치 놀이 게임 프로토타입입니다.

## 현재 구현
- 첫 실행 시 외계인 방문 이벤트
- 외계인 초대
- 마우스/터치 드래그
- 간식 / 놀이 / 낮잠 상호작용
- 친구 목록에서 추가 외계인 초대
- 큰 터치 버튼 중심의 모바일 UI
- PC/모바일 반응형 레이아웃
- 별 모으기와 간단한 말풍선 피드백

## 실행
빌드 도구가 필요 없는 단일 HTML 게임입니다.

`index.html`을 브라우저로 열거나 GitHub Pages로 배포하면 바로 실행할 수 있습니다.
